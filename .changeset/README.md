# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a tool to manage versioning and changelogs. Read the full documentation at https://changesets.dev.

We also have a quick list of common questions to get you started engaging with this project in our [FAQ](https://changesets.dev/faq).

## Cuándo añadir un changeset

Cualquier PR que toque `skills/**` debe incluir un changeset (`npm run changeset`). Los cambios en `research/`, el README o la CI no lo necesitan.

## Qué bump elegir

La colección se versiona como un todo (ver [GLOSSARY.md](../GLOSSARY.md)).

- **major**: se elimina o renombra una skill, o cambia su nombre o su trigger de forma que deja de activarse donde antes lo hacía.
- **minor**: se añade una skill nueva o se añaden capacidades a una existente.
- **patch**: se corrigen o pulen instrucciones, redacción o ejemplos sin cambiar cuándo ni para qué se usa la skill.

Mientras la versión sea `0.x`, los cambios que rompen compatibilidad pueden ir como `minor`.
